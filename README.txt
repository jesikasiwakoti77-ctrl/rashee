RASHI'S SWEET 16 — HOW TO USE

1. Open index.html in a browser for the welcome page.
2. Click the surprise button to go to letters.html (3 envelopes per row on desktop).
3. Click an envelope to open its own letter.html reading page.
4. Edit letters-data.js to replace the [Paste letter ...] placeholders with real messages.
5. Keep backticks (`) around each message. Do not put a backtick inside the letter text.
6. Envelope progress is saved in the browser's local storage. Clear site data to reset.

All pages work without a server. Google Fonts need internet, but fallback fonts work offline.
